## Publicar (GitHub Pages)

Settings → Pages → Deploy from a branch → `main` / `(root)`.

URLs (usar no Google Cloud → tela de consentimento OAuth):

- Página inicial: `https://yurialvesbordin.github.io/AnoteAI-Page/`
- Política de Privacidade: `https://yurialvesbordin.github.io/AnoteAI-Page/privacidade.html`
- Termos de Uso: `https://yurialvesbordin.github.io/AnoteAI-Page/termos.html`

Domínio autorizado no Google Cloud: `yurialvesbordin.github.io` (verificar posse no [Google Search Console](https://search.google.com/search-console) com o arquivo HTML na raiz deste repositório).
